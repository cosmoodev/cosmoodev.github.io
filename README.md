# Портфолио cosmo

Статический сайт-портфолио начинающего frontend-разработчика. Свёрстан без сборки и фреймворков: HTML, CSS и JavaScript.

## Структура

- `index.html` — главная страница с резюме, проектами и контактами.
- `styles.css`, `script.js` — оформление и интерактивность.
- `projects/coffee/` — учебный концепт кофейни «Север».
- `projects/barber/` — учебный концепт барбершопа «FORM».
- `assets/` — превью проектов, favicon и обложка для соцсетей.
- `resume.pdf` — резюме для скачивания.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000/`.

## Публикация

```bash
./deploy.sh "Обновить портфолио"
```

Сайт публикуется через GitHub Pages из ветки `main`.

## О проектах

Оба проекта — учебные концепты для портфолио. Бренды и контент вымышлены, формы работают в демонстрационном режиме и не отправляют данные.
